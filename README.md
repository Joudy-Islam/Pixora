# Pixora
A pixel art studio website where you can create, edit, and animate pixel art
## Features
* Pixel art canvas
* Color selection
* Pencil tool
* Eraser tool
* Multiple grid sizes
* Saving as PNG and GIF
* Animation
## Built with
* HTML5
* CSS3
* JavaScript
## Getting Started

### Clone the repository

git clone https://github.com/Joudy-Islam/Pixora.git
